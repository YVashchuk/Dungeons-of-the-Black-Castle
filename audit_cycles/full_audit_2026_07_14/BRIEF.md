## 2. Канон и порядок истины (обязательно к применению)

Проект — ремейк русской книги-игры Д. Браславского «Подземелья Чёрного замка» (1991, ремастер на 1221 параграф). **Источник правды — русский текст.** Иерархия при расхождениях:

1. `assets/text_corrections.json` — **леджер адьюдицированных решений**. Каждое осознанное отступление от FB2 задокументировано группой/пунктом. **Закрытые решения (DONE/VERIFIED_RESOLVED) не переоткрывать** без новых доказательств; если у вас есть контрдоказательство — оформляйте находку со ссылкой на конкретный пункт реестра.
2. `assets/fb2_remake.fb2` — первичный канон текста и механик.
3. `assets/book_1991_extracted.txt` — издание 1991 г. (исторический référence).

Переводы EN/FR/UK сверяются с **русской локалью** (`src/locale.ru.js`), не с FB2 напрямую.

## 4. Как запускать верификацию (портабельно, POSIX-проверено)

```
cd tests && npm install && node run_all.js        # 16 харнессов + baseline 1205, exit 0
node tests/_dist_art_check.js                     # и остальные пять _dist_*_check.js, каждый exit 0
```

`run_all.js` сам поднимет `python`→`python3` фолбэк при отсутствии `python`. В архиве без картинок `_dist_art_check.js` упадёт на walk-проверках `dist/art` — это ожидаемо, прогоняйте его только на полном клоне либо пропустите с пометкой.

**D. Терминология и имена.** Механические лексемы (SKILL/STAMINA/LUCK/Attack Strength и эквиваленты), словарь врагов ↔ прозаические статблоки (регистр, точные имена, порядок слов), апострофы (все четыре локали теперь строго типографские — проверьте, что это так везде), FR-пунктуация (после нормализации: NNBSP перед `?!;`, NBSP перед `:` — проверьте полноту и отсутствие регрессий).

**E. Реестр, документация, тесты.** Валидность и непрерывность version_history до v2.125; соответствие README фактам; консистентность SMOKE-документа; переносимость и честность exit-кодов тестов.

**F. Литературная вычитка (выборка).** ≥15 текстов на язык: обязательные §§1, 131, 203, 372, 417, 528, 688, 796, 950, 992, 1113, 1123, 1131, 1175, 1220 + случайная добивка с фиксированным seed. Регистр повествования, естественность, типографика.

1. Пройдите **каждый** пункт каталога модификаций (damage, player_attack_mod, скрипты, allowlist'ы, fatal-unlucky, союзники, предметы-переносчики, экономика заклятий/золота) и сверьте с FB2-текстом соответствующего параграфа: значение, знак, условие, охват.

## 6. Формат отчёта

Один `REPORT.md`, разделы строго: **1. VERIFIED-OK** (по блокам, с объёмами) → **2. FINDINGS** (таблица: id | блок | severity **P0/P1/P2** | §§/ключи | evidence | suggested fix; каждая находка — **гипотеза** с проверяемым доказательством) → **3. COUNTS** (сводные таблицы объёмов) → **4. NOT-CHECKED** (что и почему не проверялось). Севериті: P0 — навигация/данные ломают игру или канон-механику; P1 — текст/терминология/механика с заметным эффектом; P2 — косметика/доки/тесты. Внешний веб-канон не использовать.
