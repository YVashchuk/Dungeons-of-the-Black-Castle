| Защита от случайного pull-to-refresh | Проверять на настоящих scroll-контейнерах и устройствах. Сохранение важнее одной CSS-декларации |
| Постоянный `will-change` гарантирует GPU и плавность | Не принимать без измерения; `color` не становится compositor-анимацией от этого свойства |
| Phaser/Pixi/частицы/дополнительные библиотеки | Для исправления текущих проблем не нужны. DOM-ридер и SVG-карта подходят задаче |
| TTS | Возможное отдельное улучшение. Код из PDF повреждён и не пригоден для вставки; нужны выбор голоса/языка, пауза, остановка при смене§. Офлайн-работа зависит от устройства и голоса |

Текущие цены, лимиты и модели внешних голосовых сервисов не проверялись и не рекомендованы как подтверждённые. Для статического текста можно рассмотреть заранее подготовленные аудиофайлы по языку/версии/параграфу; при генерации по запросу секрет не должен находиться в клиентском HTML. Полный отдельный разбор всех шести страниц: [GEMINI_review.md](GEMINI_review.md).

Приложенная карта Gemini пригодна как художественное направление, но не как навигационная основа: связи не подтверждены, есть псевдотекст, смешение языков, `Barld Dert` и преждевременные спойлеры. ## 7.7. Короткий адрес DotBC

Корневой `index.html` **уже существует**: в архиве он перенаправляет на `dist/dungeons-of-the-black-castle.html`. Поэтому корень проекта предусмотрен как более короткий вход; отдельно в сети он не открывался по ограничениям задания. После такого перенаправления адресная строка снова становится длинной.

Для адреса, остающегося коротким, предпочтительна публикация основного entry как `index.html` под коротким путём `/DotBC/`, со старым адресом как совместимым перенаправлением. Более простой alias сокращает ввод/передачу ссылки, но после перехода оставляет длинный адрес. Переименование вкладки в DotBC URL не меняет. Ничего не переименовывалось и не публиковалось.

```js
// Пример логики отдельного короткого alias; не применён к сайту.
// Сохраняет разрешённый номер параграфа из старой закладки.
const target = '/Dungeons-of-the-Black-Castle/dist/dungeons-of-the-black-castle.html';
location.replace(target + location.hash);
```

Перед публикацией проверить относительные art/sound пути, старые закладки с`#N` и существующие сохранения. Перенос на другой origin сам по себе сохранения не переносит. Конкретный способ размещения короткого пути нужно согласовать с владельцем проекта после подготовки отдельного изменения.
