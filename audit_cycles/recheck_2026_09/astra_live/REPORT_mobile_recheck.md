## 7.1. Условия повторной проверки

Браузер Chrome, 1363×936 CSS px, DPR1. Клики, ввод, Tab/Shift+Tab, Enter, Esc, M и штатная перезагрузка доступны. Изменение размера, эмуляция 412×915, приватное окно и переключение раскладки ОС недоступны. Физическая клавиша F5 не подтверждена; проверки сохранения выполнены командой перезагрузки браузера. Снимки Pixel пользователя имеют 921×2048 пикселей; по ним нельзя достоверно восстановить CSS viewport, DPR и доступную высоту без системных панелей.

Использованы два разных вида доказательств: **A — действия в живой игре на desktop; B — оценка пяти присланных снимков Pixel**. Расчёты по CSS и отдельный макет не называются эмуляцией Pixel. Android/iOS, экранная клавиатура, поворот и системные жесты не испытаны. Полный PDF дискуссии с Gemini прочитан; ссылки из него не открывались. Другого веб-использования не было.

Архив служил справочником. Исходники и развёрнутый сайт не изменялись, архивный runtime не запускался. Состояние игры менялось только обычными действиями интерфейса и разрешённым `#N` в smoke. Чистые тестеры создавались через «Новая игра»; это не подмена приватного окна. Сохранения не импортировались, предметы вручную не добавлялись, броски не подменялись. Чтение DOM и вычисленных стилей использовалось только для наблюдения интерфейса.

## 7.3. Грамматика других боёв

Статически просмотрены все 76 боевых параграфов, 120 записей врагов и 66 уникальных идентификаторов. Это охват каталога и генератора сообщений, не 76 проведённых боёв. Живые примеры получены у змей, льва/львицы, разбойников и в прежнем прохождении.

Нужно исправлять также «не смогла», «победила», «ослаблена», винительный и творительный падежи. Ошибка шире женского рода: «Вы ранили ПЕРВЫЙ ГОБЛИН» и «Ничья с ОГРОМНАЯ ЗМЕЯ» требуют других форм. Аналогичная сборка фраз есть в UK; во FR нужно проверить `affaibli/affaiblie`. Литералы `\u202f` и `\xa0`, видимые в диагностическом представлении строк, оказались корректными неразрывными пробелами: эта гипотеза ошибки снята.

Практичный первый вариант без словаря склонения: «Огромная змея: урон герою −2; ваша выносливость18/20» и «Ваш удар → Огромная змея: −2; выносливость врага4/6». Для литературного «Змея ранила вас» нужен словарь грамматических форм по языку и идентификатору врага. Глобальная замена «ранил» на «ранила» сломает остальные сообщения.

Почему остались не-PASS:

- **C1, C15, C16, C17, C19, B1, B5 — BLOCKED:** соответственно приватное окно, ширина≥1400, мобильные режимы/жесты/поворот и русская раскладка ОС. Доступные механические части выполнены. Снимки Pixel не доказывают взаимодействие и размеры всех областей нажатия.
- **C14 — FAIL:** конкретное выпадение Close карты из общей типографики. Все четыре языка проверены на титуле, в меню, карте и бою; вычисленный стек не выдаётся за доказательство конкретного файла шрифта для каждого глифа.
- **A7 — прежний FAIL:** переход737→182 теряет оставшегося первого гоблина; затем скрываются доступные заклятия (PL-41/43). Эти сценарии уже были выполнены, поэтому они не считаются пропущенными и не объявлены исправленными новым аудитом.
- **C6 — UNCLEAR:** строка требует красную рамку, §1 того же brief — золотую. Наблюдается золотая; выбор и−2 работают.
- **B2 — UNCLEAR:** состояние «убежал» недостижимо в указанном628. Оно проверено в1175 после удачного броска6+2=8; остальные состояния и HP-полосы наблюдаются. Исправить адрес тестового сценария.
- **C7 — UNCLEAR формулировки:** после победы617 специальной кнопки нет; следующий бой250 проверен непрерывной цепочкой617→1140→17→250 обычными кликами, без оставшейся кнопки. Прямой переход к43 требует reload, который очищает проверяемое состояние; естественный путь содержит промежуточные бои. Функциональная очистка подтверждена, исходную методику надо уточнить.

Точный разбор двух ошибочных сценариев: [C7/B2](C7_B2_clarifications.md). Старый BLOCKED для C12 был избыточен относительно полной smoke-строки: она требует заряд Силы, но не private. В новой таблице это **исторический функциональный PASS**, без притворного нового запуска приватного окна.

Особенно показательный новый опыт A5: Копия убила второго разбойника, медведь — пятого; собственные убийства произошли в раундах2,5,8. После первых двух своих убийств всё ещё +7; после третьего зелье истекло, в следующем бою остались+2 меча/щита. Отдельно ранее в этом дополнении наблюдались+6 со «Смертью Орков». ## 7.7. Короткий адрес DotBC

Корневой `index.html` **уже существует**: в архиве он перенаправляет на `dist/dungeons-of-the-black-castle.html`. Поэтому корень проекта предусмотрен как более короткий вход; отдельно в сети он не открывался по ограничениям задания. После такого перенаправления адресная строка снова становится длинной.

Для адреса, остающегося коротким, предпочтительна публикация основного entry как `index.html` под коротким путём `/DotBC/`, со старым адресом как совместимым перенаправлением. Более простой alias сокращает ввод/передачу ссылки, но после перехода оставляет длинный адрес. Переименование вкладки в DotBC URL не меняет. Ничего не переименовывалось и не публиковалось.

```js
// Пример логики отдельного короткого alias; не применён к сайту.
// Сохраняет разрешённый номер параграфа из старой закладки.
const target = '/Dungeons-of-the-Black-Castle/dist/dungeons-of-the-black-castle.html';
location.replace(target + location.hash);
```

Перед публикацией проверить относительные art/sound пути, старые закладки с`#N` и существующие сохранения. Перенос на другой origin сам по себе сохранения не переносит. Конкретный способ размещения короткого пути нужно согласовать с владельцем проекта после подготовки отдельного изменения.

## 7.9. Что ещё нельзя считать проверенным

Физические Pixel7a/iPhone15/Windows laptop как отдельные платформы; экранная клавиатура в имени/загадке; touch-отклик iOS; поворот; pull-to-refresh; размеры всех целей нажатия на телефоне; работа со скринридером на слух; производительность и энергопотребление; новая TTS; полный литературный вычит всех1221 параграфа; новый физический private/F5 и раскладка ОС. Исторические логи, G-таблица, маршруты и52 карточки замечаний остаются доступны вместе с новыми снимками. Изображения макета и схемы маршрута обозначены отдельно от доказательных скриншотов.
