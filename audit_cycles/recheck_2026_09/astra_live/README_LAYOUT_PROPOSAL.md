# Предложение мобильного интерфейса DotBC

- `MOBILE_LAYOUT_PROPOSAL.html` — автономный адаптивный HTML-макет: откройте локально; внешние ресурсы и игровой движок отсутствуют. На телефоне четыре примера идут друг под другом, на широком экране — в две колонки. Это статичный дизайн, кнопки не выполняют игровые действия.
- `MOBILE_LAYOUT_PROPOSAL.svg` — отдельный векторный обзор на логической ширине412px.
- `MOBILE_LAYOUT_PROPOSAL.png` — этот же обзор824×5090px, масштаб2×. Создан средствами векторной разметки/Pillow, **не снимок браузера и не подтверждение внедрения**.
- `build_layout_preview.py` — воспроизводимый генератор SVG/PNG; читает только системные шрифты, не проект игры.

HTML и обзор используют одну композиционную идею, но не являются пиксельно идентичными: HTML рендерится системными браузерными шрифтами, обзор — DejaVu. Просмотр PNG выполнен визуально, текст и основные элементы не перекрыты.

Показаны: карточки с описанием на всю ширину и +/−44×44; отдельная колонка для стрелки выбора; Close наверху справа в карте; два явно подписанных типа урона; способности над центральной нижней кнопкой «Удар!». Картографические точки и линия — условный демонстрационный рисунок, не каноническая география и не извлечённый маршрут игрока.

Проверка предложенного CSS на живой игре не выполнялась и из этого макета не следует.
